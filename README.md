# KarlAstra — Astra Anime Client для Minecraft 26.2

Клиентский Fabric-мод, перенесённый с Astra Anime Client 1.21.11. Исходники восстановлены из оригинального JAR; автор оригинала — **Adelionis**. В метаданных оригинала указана лицензия MIT. Оригинальные ресурсы и модули сохранены.

## Установка

Нужны Minecraft **26.2**, Java **25**, Fabric Loader **0.19.3+** и Fabric API **0.161.0+26.2**.

Положите основной `KarlAstra-0.2.0+26.2.jar` и Fabric API в папку `mods`. JAR с окончанием `-sources` нужен разработчикам. Старую Astra 1.21.11 одновременно устанавливать не нужно. Открытие меню — **Right Shift**.

## Дополнительные настройки

* **Свои аватары:** положите изображения в `config/astra/art` — ту же папку, которую использует компаньон. В разделе «Косметика» → «Рамка и аватар» → «Аватар» выберите `Файл: имя.png`. Доступны PNG, JPG/JPEG, BMP и GIF через существующий загрузчик; GIF отображается статически. Изображения обрезаются по центру без растягивания. При удалении файла используется встроенный аватар.
* **Свой тег:** в том же модуле выберите «Тег» → «Свой» и заполните «Свой тег» (до 32 символов). Встроенные теги и старые настройки продолжают работать.
* **Приветствие:** «Звуки» → событие входа на сервер/в мир → включите «Надпись при входе» и «Своё приветствие». Можно изменить заголовок и подпись, затем нажать «Показать». Без своего текста сохраняются прежние подписи звуков.

Эти настройки сохраняются существующей системой конфигурации и профилей Astra.

## Сборка

Установите **JDK 25** и задайте `JAVA_HOME`. Gradle Wrapper закреплён на **9.5.1**, Loom — на **1.17.17**. Контрольная сумма дистрибутива Gradle закреплена в настройках wrapper.

Windows: `.\gradlew.bat build`. Linux/macOS: `./gradlew build`.

Результат: `build/libs/KarlAstra-0.2.0+26.2.jar`.

## Автоматические проверки

Workflow **Build Minecraft 26.2 mod** запускается для push и Pull Request:

1. Компилирует все исходники и собирает JAR на Java 25.
2. Проверяет метаданные, наличие всех настроенных Mixins и исходных ресурсов в JAR.
3. Запускает клиент под Xvfb с программным OpenGL, загружает все классы с Mixins и отрисовывает главное меню и ClickGUI.
4. Проверяет загрузку своего аватара и сохранение/чтение тега и приветствия через конфигурационный файл.
5. Публикует артефакт `KarlAstra-26.2`, журналы клиента и снимок интерфейса.

Локальная проверка: `./gradlew runClient -PsmokeTest`. Этот режим предназначен для изолированной тестовой папки `run`: создаёт тестовый аватар, временно меняет настройки, проверяет их и закрывает клиент. В обычном запуске он выключен.

Workflow **Recover original Astra sources** сохранён для воспроизводимости восстановления. Он публикует исходники в артефакт и больше не перезаписывает порт автоматическим коммитом.

## Проверка непосредственно в Minecraft

Автоматический запуск меню не заменяет игровые испытания. Проверьте в одиночном мире и на сервере:

* HUD, миникарту, метки, холсты, частицы и эффекты цели;
* косметику своего и другого игрока, щит, анимации рук, FOV и время суток;
* чат, подсказки команд, прокрутку, Tab и экраны других модов;
* звук входа и приветствие, MP3/WAV/OGG, музыку и интеграцию с медиаплеером Windows;
* реплеи, скриншоты, переключение профилей и изображения разных размеров;
* совместимость с Iris/другими модами и экспериментальным Vulkan отдельно.

Порт использует API извлечения состояния и отложенные `SubmitNodeCollector`-вызовы Minecraft 26.2. Проверка OpenGL не подтверждает работу всех эффектов на Vulkan.
